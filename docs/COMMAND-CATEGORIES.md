# Command Categories

These folders are included from the start so the project can grow without repeatedly reorganizing its command tree.

| Folder | Intended responsibility |
|---|---|
| `administration` | Server administration |
| `automation` | Automation and scheduled workflows |
| `configuration` | Server and bot configuration |
| `economy` | Economy and progression systems |
| `fun` | Entertainment commands |
| `information` | Information and lookup commands |
| `moderation` | Moderation and safety tools |
| `owner` | Bot-owner-only commands |
| `tickets` | Ticket and support workflows |
| `utility` | General-purpose utilities |

Not every project needs every category. Empty directories are kept as architectural placeholders for teams that want a stable structure from the beginning.
