# Security Policy

Please do not publish security vulnerabilities in public issues.

For a real vulnerability, contact the repository maintainer through the private security channel configured for the GitHub repository.

## Basic rules

- Never commit `DISCORD_TOKEN`.
- Never log secrets.
- Keep dependencies updated.
- Validate environment variables.
- Verify Discord permissions in code.
- Do not expose internal errors to users.

Security improvements and responsible disclosures are welcome.
